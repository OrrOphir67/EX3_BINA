הוראות הרצה - מטלת Perceptron
===================================

1. הכנת הסביבה
   -------------

   א. יצירת סביבה וירטואלית:
      python -m venv venv

   ב. הפעלת הסביבה:
      Windows: venv\Scripts\activate
      Linux/Mac: source venv/bin/activate

   ג. התקנת תלויות:
      pip install -r requirements.txt


2. הכנת קבצי הנתונים
   ------------------

   צריך ליצור תיקייה בשם digitdata ולהעתיק אליה את הקבצים:
   - trainingimages
   - traininglabels
   - testimages
   - testlabels

   מבנה התיקיות צריך להיות:

   EX3_BINA/
   ├── digitdata/
   │   ├── trainingimages
   │   ├── traininglabels
   │   ├── testimages
   │   └── testlabels
   ├── perceptron.py
   └── run_experiments.py


3. הרצת הניסויים
   --------------

   להריץ את כל הניסויים (שני הווריאנטים):

   python run_experiments.py

   הסקריפט יריץ:
   - ווריאנט 1: קצב למידה קבוע α=1
   - ווריאנט 2: קצב למידה יורד (α=1, מוכפל ב-0.8 אחרי כל epoch)

   עבור כל ווריאנט:
   - אימון למשך 4 epochs
   - דיווח על שגיאות אימון אחרי כל epoch
   - דיווח על שגיאות במבחן בסוף
   - מטריצת בלבול (confusion matrix)


4. תוצאות
   -------

   התוכנית תציג על המסך:

   ✓ מספר שגיאות אימון אחרי כל epoch (עבור שני הווריאנטים)
   ✓ מספר שגיאות על מבחן בסוף הלמידה
   ✓ מטריצות בלבול מפורטות
   ✓ ניתוח שגיאות לפי ספרה

   קבצי פלט:
   - confusion_matrix_variant1.txt
   - confusion_matrix_variant2.txt


5. הבנת הפלט
   -----------

   מטריצת הבלבול:
   - שורות = תווית אמיתית (i)
   - עמודות = תווית חזויה (j)
   - אלכסון = סיווגים נכונים
   - סכום המטריצה = 1.0 (100%)

   דוגמה:
   אם בשורה 3 (ספרה 3 אמיתית) ובעמודה 8 (חזוי 8) יש 0.012,
   זה אומר ש-1.2% מכל הדוגמאות היו ספרה 3 שסווגה בטעות כ-8.


6. בעיות נפוצות
   ------------

   שגיאה: "No module named 'numpy'"
   פתרון: pip install -r requirements.txt

   שגיאה: "FileNotFoundError: digitdata/trainingimages"
   פתרון: וודא שתיקיית digitdata קיימת עם כל הקבצים הנדרשים

   שגיאה: "ImportError"
   פתרון: וודא שהסביבה הוירטואלית מופעלת


7. דרישות המטלה
   -------------

   המטלה דורשת לדווח על:

   1. מספר השגיאות עבור דוגמאות האימון אחרי כל epoch
      ✓ הסקריפט מדפיס זאת אוטומטית

   2. מספר השגיאות עבור דוגמאות המבחן בסוף הלמידה
      ✓ הסקריפט מדפיס זאת אוטומטית

   3. מטריצת בלבול - אחוז המקרים שבהם דוגמא מסוג i סווגה כסוג j
      ✓ הסקריפט מדפיס ושומר למקובץ
